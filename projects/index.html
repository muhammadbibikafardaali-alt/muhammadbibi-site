  2. P-003 · 2026 Delivered

    The Insider: IT practice platform

    ProblemTesting yourself is the fastest way to make knowledge stick, but students starting in IT had no free, structured way to check what they really know.

    BuiltA bilingual Arabic and English practice platform with 15 tracks, from Linux, networking and cybersecurity to cloud, DevOps, Python and AI prompting, and about 730 questions. Each track has up to five levels of ten questions; the next level unlocks at 70%.

    How it worksNext.js App Router with dynamic routes per track and level. Questions live in typed TypeScript data files, so adding a track is adding one file. Progress (best score, attempts, XP, streaks and weak topics) is saved in the browser, so there is no backend to run. Full right-to-left support for Arabic. Answer options were rebalanced so the correct one never stands out by length.

    Next.js 15React 19TypeScriptTailwind CSSi18n / RTLVercel

  3. P-002 · 2026 Delivered

    IT Roadmap generator

    ProblemFirst-year students often do not know which IT field suits them, or where to start once they choose one.

    BuiltA step-by-step tool in Arabic that asks six questions: the track (front end, back end, full stack, cybersecurity, data, mobile, DevOps or networking), current level, hours per week, goal, main obstacle and device. It returns a personal roadmap.

    How it worksThe answers select a roadmap template for that track and level. Each phase has a duration, topics, a hands-on project and curated free resources, and the advice adapts to the obstacle and device the student chose. Built as a single React app with Vite, fully client-side, deployed as a static site.
